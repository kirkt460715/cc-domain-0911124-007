# 量衡

记录仪器、通道、单位、校准证书及测量批次，执行质量策略并封存测量窗口。校准适用期、来源水位和序列缺口均可追查。

演练接收合成压力读数，完成校准、窗口封存及导出证明核验。测量值与不确定度使用各自明确的单位。

实验室间能力验证按轮次进行：登记实验室、试件、测量项目、提交截止、重复测量规则与评价分界后开放提交；提交关联已有测量及其证书修订，同一测量不能服务两个参与者。指定值可来自独立参考证书（来源、标准或扩展不确定度与覆盖因子必须明确），或以各实验室汇总值的中位数与 1.483 倍 MAD 形成稳健共识，并给出参与数与逐实验室剔除敏感性。评价提供按预定能力标准差的 z 分数，双方标准不确定度齐全时提供 zeta；共享参考沿登记的协方差计算，缺少相关性依据时限定解释，缺失与零尺度不强行计算。轮次关闭后保留原提交、迟交、撤回与证书失效状态；重开或改参考产生新的评分版本，既有通知不原地变更。分数仅适用于本轮提交结果，不构成方法等效性结论。

主要代码位于 metrology，按 ledger、ingress、calibration、processing、output、proficiency 划分职责；tests 保存领域行为、边界及存储回归用例。命令接收严格 JSON，详细操作名与字段可通过对应帮助入口及 service 中的注册表查询。示例中的机构、客户、案件和测量均为本地合成记录，不涉及真实个人资料。

使用 Python 3.11.2 与标准库，无第三方包。运行无需访问外部服务或提供账号。依赖清单 requirements.txt 为空，.python-version 固定解释器版本。

在项目根目录运行：

```sh
python3 -m unittest discover -s tests -v
python3 -m compileall -q metrology
python3 -m metrology demo
```

也可执行下面的统一检查，按顺序进行语法编译、领域回归和完整本地演练，任一环节失败即退出。运行写入均在临时目录或内存数据库，重复执行不需清理已有业务账。正常数据规模的检查可在 90 秒内完成。

```sh
sh scripts/check.sh
```
